# AI 语音前台套件

## 适用场景
- 前台电话过滤（单体酒店日均 20–50 通，60–80% 为重复问题）；民宿业主夜间免打扰；无人酒店唯一人工入口的 AI 前置层

## 触发条件
- 电话呼入事件（phone_call 对象）；FAQ 知识库每周日 03:00 自动萃取更新

## 输入数据
- 通话语音/转写、一店一档 faq_kb（高频问题 top20 + 答案 + 来源通话归因）、一店一档基础档案（地址/停车/早餐/WIFI/政策）、在住房态（仅应答类查询）

## 方法
1. 接听与意图识别：24h 即时接听；意图分类为「高频咨询 / 预订意向 / 投诉 / 特殊需求 / 疑似欺诈 / 外部推销」。
2. 高频咨询自动应答：命中 faq_kb 即答（房价区间/地址导航/停车场/早餐时间/WIFI/退房时间/发票政策）；答案与一店一档同源，口径统一，消除「不同前台回答不一」。
3. 三级转人工：投诉关键词（差评/赔偿/退款争执）→ 转人工并预生成安抚话术；特殊需求（加床/特殊枕头/延迟退房）→ 常规项围栏内自动记录派单，非常规转人工；疑似欺诈（索要验证码/异常支付引导）→ 立即挂断并告警。
4. 预订意向引导：播报实时房价区间与可售状态，引导 OTA/小程序下单；不直接收款、不做涉费承诺（R13 管辖）。
5. 通话摘要留痕：每通电话生成五元事件（phone_call::call.summary：意图/结论/转人工与否/时长），全量可回溯。
6. FAQ 知识库自动萃取：每周对通话摘要做聚类，新问题出现 ≥3 次自动进入 faq_kb 候选，店长一键确认入库（非人工录入的静态 FAQ，知识库自我生长）。

## 输出动作
- 应答记录/转人工工单/派单任务/通话摘要事件/FAQ 候选清单

## 对接系统
- 语音线路/ASR/TTS、PMS 只读查询、IM 班组（转人工通道）、一店一档 faq_kb

## 围栏绑定
- 纯应答 auto；涉费承诺 → R13 review；触达外呼（如回访）→ R9 触达合规 block 红线；夜间（22:00–08:00）转人工默认转值班手机而非叫醒店长（民宿版：夜间全托管，次日清晨决策包汇报）

## 验收用例
- 正常路径：呼入「有停车场吗」→ 命中知识库即时应答 → 通话摘要写事件库 → 前台零打扰
- 异常路径：客人电话投诉噪音 → 投诉关键词识别 → 转人工 + 安抚话术预生成 + 事件留痕
- 围栏触发：客人要求「电话里先收定金留房」→ 涉费承诺 R13 review 挂起；夜间高频咨询 → 自动应答不叫醒任何人，次日进决策包
