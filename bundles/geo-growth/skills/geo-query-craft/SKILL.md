# query 集建设（四词类 × 双语）

## 适用场景
- 建档期 D5-D7 query 集 v1 建设（GEO 班组+客户确认）
- 日常 query 集扩充与优先级调整

## 方法
1. 四词类模板（附录 A）：
   - 品牌词：「XX 机械怎么样」「XX 机械 vs YY」——口碑监测
   - 品类词：「CNC 加工厂家哪家好」「激光切割机怎么选」——首推率争夺主战场
   - 场景词：「小批量定制零件找什么供应商」「出口欧洲的机械认证要求」——长尾覆盖
   - 竞品对比词：「XX 和 YY 哪个好」「替代 YY 的中国供应商」——截流
2. 每词六字段：语言、目标市场、优先级、当前能见度状态、关联 GEO 内容、关联短视频选题。
3. 中英双语 50-100 条起步；客户确认优先级后落一客一档 GEO 资产。
4. 与情报站联动：AI 问答高频新问题持续补入 query 集。

## 输出契约
- 输出：query 集（四词类分栏 + 六字段全填），客户确认版标 confirmed。
- 词类覆盖率检查：四类词缺一不可；优先级字段必须经客户确认。
- 无工具回执的词频数据标「未核实」，不得宣称完成。
