# 团购券运营（coupon-ops）

> 获客五环④转化环的第一转化品。「先囤后约」把决策做到极致轻量化——用户看到优惠先下手，酒店提前锁定未来入住。

## SKU 设计公式

```
券价 = 门市价 × 0.7~0.85（且 ≥ 保底价×0.85，R26 红线）
权益 = 房型 + 早餐/延迟退房等低成本高感知权益
限制 = 有效期 90-180 天 + 法定节假日不可用（保护旺季收益）+ 不约可退
```

## 与内容的联动纪律

- 推什么内容挂什么券：亲子内容挂亲子券、商旅内容挂商旅券；
- 房态联动：满房日期自动关券（防超卖投诉），淡季猛推（填谷）；
- 售罄/下架即熔断：相关内容停投、AI 接待话术切换、直播口播换品（R22）。

## 核销对账（三轮比对口径）

1. 平台核销记录 ↔ PMS 入住记录 ↔ 券库存扣减，三方一致；
2. 核销率周报复盘：<30% 预警（内容-券不匹配）/ >90% 预警（定价偏低或黄牛）；
3. 未核销到期券：自动退款 + 二次触达（「你的券快到期了」= 免费再营销）。

## 红线

- 券价 < 保底价×0.85 → 熔断（R26）；
- 券文案权益口径与一店一档一致（R25）；
- 库存=0 后任何渠道的售卖动作 → 熔断（R22）。
