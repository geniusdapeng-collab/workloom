# OTA 运营套件

## 适用场景
- 各 OTA 活动报名决策；渠道信息合规巡检；活动价格冲突检测

## 触发条件
- 活动报名截止前 3 天 + 每日渠道巡检

## 输入数据
- 各渠道活动列表、历史活动效果数据、一店一档 channels/business.commission_rules、price_calendar

## 方法
1. 活动评估：按历史效果/佣金成本/库存压力生成参不参与建议，附数据支撑。
2. 冲突检测：活动价与日常价/价格日历冲突 → 标注并给出同步方案。
3. 合规检查：渠道图片/文案/信息合规（首图实拍/无水印/16:9 等品牌规范）。
4. 排名监控：关键词排名/流量变化，异常下滑 P1 提醒。
5. 纪律：活动报名经店长 review 确认后执行；不参加策略也留痕。

## 输出动作
- 活动报名建议（待审）/冲突检测报告/合规整改清单

## 对接系统
- 携程/美团/飞猪等 OTA 后台

## 围栏绑定
- 活动报名 review（default_level）；涉改价动作 R1/R2 同源

## 验收用例
- 正常路径：活动截止前 3 天 → 评估建议 → 店长确认 → AI 执行报名 → 留痕
- 异常路径：店长未及时决策 → 按默认策略（不参加）处理并留痕
- 围栏触发：活动价低于保底价 → R2 block + 冲突报告
